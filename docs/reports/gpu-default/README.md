## 本轮检查

- 主机 CTest 14/14，包括 108 个能力/诊断模式/开关组合的默认策略单元测试。
- RTX 4060 Laptop 与 AMD Radeon(TM) Graphics：未设置、显式 auto、三项强制 1、三项关闭、部分关闭的完整预测一致；CLS 开/关、独立句柄交替运行、空图与低预算恢复通过。
- 两卡默认 GPU 裁剪：各 111 个像素对照场景，精确相等；Khronos 同步验证已激活，未发现 VUID/SYNC-HAZARD。
- 三模型网络变尺寸/LRU/回读 canary、低预算拒绝恢复；私有 2448×3264 Medium 原图 DET960 重复五次，85 个区域一致。不保存图片或 OCR 内容。
- 真实 HTTP 默认调用：二进制/Base64、仅识别/批量、认证、异常输入、日志、队列 429、等待 503、恢复与关闭通过。
- 完整 C# 包 staged 验证：移除 SDK/开发 PATH、外部工作目录，两卡三模型整图/ROI；RTX 显式 CPU 前处理三模型；WinForms RTX 五次、AMD 两次以及 GPU 编号/鼠标映射/JSON 表格检查。

报告按文件保留，完整 ZIP 解压后的校验与 C# 复测另置于 ZIP 旁 `.validation.json`，不能把 staged 测试当成最终压缩包复测。

## 默认切换的性能对照

两边三个环境变量均未设置：旧 DLL `518073024b6d39cc18b6357b3475c0015ae3a6bea732b214e4753efc1daeafa6` 默认 CPU 图像处理；新 DLL 在 RTX 4060 上自动使用完整 GPU 图像处理。两边网络 FP32、CLS 开、DET960、同模型同图，逐项预测完全一致。
